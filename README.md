# Desktop Pet

Gentle, fully offline reminders delivered by a cartoon companion in a speech bubble. Runs in the background
(no taskbar button, a small icon near the clock).

Companions: **Mochi** (calico kitten), **Remi** (baby sloth), **Finn** (fennec fox), **Pogo** (baby porcupine),
**Boba** (hamster). Pick one per reminder.

## Run
1. Install Python 3.9+ (`winget install Python.Python.3.12`).
2. Double-click **Start Desktop Pet.bat**. On first run the small settings window opens.
3. Optional: **Create Desktop Shortcut.bat** puts an icon on your desktop.

## Turn it into a real application (.exe)
Double-click **build-exe.bat** (needs internet once for PyInstaller). Result: `dist\DesktopPet\DesktopPet.exe`
(copy the whole folder). The exe is unsigned, so Windows Smart App Control blocks it unless that is switched off.

## Use
* **Tray icon (near the clock):** left-click = settings. Right-click = Pause/Resume, Quit.
* **Closing the settings window** only hides it; reminders keep running. **Quit** stops everything.
* **Reminders:** the companion pops up above the taskbar with a speech bubble: Done / Start break / Snooze / Not now.
  Once only, never takes focus, fades if ignored. A break countdown (e.g. 20 s eye exercise) runs inside the bubble.
  Held back while a full-screen app is running.
* **Add** > Eye break, Water, Stretch, Posture or Custom. Edit name, message, companion, "every N minutes" or
  "at 09:00, 13:30", break seconds, snooze, active hours, chime. **Preview** shows how a reminder looks.
* Messages such as "nothing is selected" and delete confirmations also appear as a companion's speech bubble.
* Data: `%AppData%\DesktopPet\data.json`. No network access of any kind (a test enforces it).

## Test
`python -m unittest discover -s tests -v`

## Changing or adding companions
See **REPLACE_IMAGES.md**. Pictures live in `tools\pets\<id>\` and are baked into `desktop_pet\assets\` by
**Rebuild Sprites.bat** (one sprite sheet per companion and size).

## Artwork
The companions' pictures were generated by the project owner with Gemini and are animated in 2D (hop, blink, happy
face). Check Gemini's terms if you plan to share or sell the app.
